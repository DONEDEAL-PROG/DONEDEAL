Storage variant selector update

On models with published Philippine variant SRPs, View Details displays a storage selector and updates the shown price immediately. Selected storage is retained when added to cart, and the cart shows each variant separately with SRP subtotal.

Only six product entries have SRP variants in the supplied source data. Other products do not show fabricated options or prices. Add verified variant prices to phVariants in app.js to enable the same feature for additional phones.

Replace app.js in your GitHub repository. No homepage image changes.
