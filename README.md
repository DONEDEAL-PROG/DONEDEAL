# Done Deal Phone and Gadgets — Demo smartphone storefront

A static, responsive ecommerce storefront prototype with 35 smartphone entries across Huawei, Samsung, OPPO, vivo, Xiaomi and Apple.

## Run locally
Open `index.html` in a browser, or serve this directory with `python -m http.server 8000` and open http://localhost:8000.

## Publish
Upload `index.html` and `app.js` together to Cloudflare Pages, Netlify or another static hosting service. No build step required.

## Before accepting orders
- Replace illustration-only product imagery with licensed official photos.
- Confirm each model's availability, specifications and regional variant.
- Add verified prices, variants, stock and shipping rules. Prices are intentionally null / "Price on request".
- Implement a secure backend with authenticated admin, orders database, stock tracking, order confirmation and transactional notifications.
- Integrate a supported payment processor. Never collect card numbers in the static site.
- Add business contact details, terms, privacy notice, returns, warranty and shipping policies.

This is a functional front-end prototype with local cart persistence and a demo-only checkout. It does NOT process real orders or payments.
